# KSTM AI

**KSTM AI** allows you to build AI assistants with your own data. Upload CSV, PDF, JSON files, or connect web sources to get a custom AI assistant in minutes.

## Features

- **Upload your data**: Drag and drop files or paste URLs. Supports 20+ formats including CSV, PDF, JSON, and web pages.
- **AI learns instantly**: Our AI processes your data and creates a custom assistant that understands your specific context and domain.
- **Share anywhere**: Get a shareable link, embed on your website, or integrate with your existing tools and workflows.
- **Video Demo**: Check out the demo video on the landing page to see it in action.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **UI Components**: [Radix UI](https://www.radix-ui.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd KSTM-AI-FRONTEND
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

   Open [http://localhost:8080](http://localhost:8080) with your browser to see the result.

## Scripts

- `npm run dev`: Runs the app in development mode.
- `npm run build`: Builds the app for production.
- `npm start`: Starts the production server.
- `npm run lint`: Runs linter.
